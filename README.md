# Хор „Свети Владика Николај Српски" - Нова Пазова

Сајт мешовитог хора при храму Свете Петке у Новој Пазови. Статичне странице на српској ћирилици, без сервера и без система за уређивање садржаја.

**Инстаграм:** [@hornovapazova](https://www.instagram.com/hornovapazova) · **Фејсбук:** [HorNovaPazova](https://www.facebook.com/HorNovaPazova) · **Јутјуб:** [канал хора](https://www.youtube.com/channel/UCHeA3i_Rdq_KfHwoMIjTJKg)

**Сајт уживо:** [cvoki.github.io/Horski-Sajt](https://cvoki.github.io/Horski-Sajt/)

## О пројекту

Хор је основан 2005. године, благословом Епископа сремског Господина Василија, и данас броји 24 члана. Сајт је требало да на једном месту окупи оно што је до тада било расуто по друштвеним мрежама: ко су, шта певају, где наступају и како им се јавити.

Решење је намерно скромно - статичан HTML, једна CSS датотека и Bootstrap. Без базе, без администрације, без месечних трошкова. Хор није имао некога ко би одржавао систем, па је боље да га и нема.

Цео садржај је на **српској ћирилици**, што за овакав сајт није техничка ситница него део карактера.

## Странице

| Страница | Садржај |
|---|---|
| `index.html` | Насловна — заглавље, навигација, подножје |
| `o_nama.html` | О хору: оснивање 2005, састав, репертоар |
| `dogadjaji.html` | Догађаји и наступи |
| `galerija.html` | Галерија — девет уграђених Инстаграм објава |
| `crkva.html` | О храму Свете Петке: историјат Нове Пазове, градња храма, житије светитељке |
| `kontakt.html` | Контакт форма и Гугл мапа са локацијом храма |

## Технологије

`HTML5` · `CSS3` · `Bootstrap 5.0` · `Bootstrap Icons` · `Instagram Embed` · `formsubmit.co` · `GitHub Pages`

Библиотеке се учитавају са CDN-а, па у спремишту стоји само оно што је писано за овај сајт. Контакт форма шаље поруке преко [formsubmit.co](https://formsubmit.co) — без сопственог налога, директно на имејл хора.

## Изглед

Боје су преузете из самог храма и црквене традиције:

| Боја | Код | Где се користи |
|---|---|---|
| Тамноцрвена | `#af1d1c` | заглавље, подножје, путања кроз странице |
| Златна | `#c7a658` | линкови при прелазу мишем, поља форме, дугмад |
| Светлосива | `#DCDCDC` | позадина странице |

Навигација користи Bootstrap `navbar` који се на ужим екранима скупља у дугме, тако да сајт ради и на телефону.

## Покретање

```bash
git clone https://github.com/Cvoki/Horski-Sajt.git
cd Horski-Sajt
```

Отвори `index.html` у прегледачу.

За локални сервер:

```bash
python3 -m http.server 8000
# па отвори http://localhost:8000
```

## Измене садржаја

- **Нова страница** — најлакше је копирати `o_nama.html` и заменити садржај, јер већ има заглавље, навигацију и подножје.
- **Навигација** — понавља се у заглављу сваке странице, па нову ставку треба додати свуда.
- **Галерија** — уграђене Инстаграм објаве; нова се додаје тако што се на Инстаграму изабере *Embed*, а добијени код залепи у `galerija.html`.
- **Изглед** — све је у `style.css`; Bootstrap класе носе мрежу и распоред.

## Шта остаје да се уради

Основни оквир и садржај су завршени, сајт је уживо на GitHub Pages. Преостаје:

- **Праве фотографије** хора, храма и наступа — тренутно их нема у репозиторијуму (`crkva.html` има означена места за њих).
- **Прави датуми и места** наступа на `dogadjaji.html` — тренутно су ту само оквирне (placeholder) картице.
- **Прави лого/фавикон** хора — тренутно стоји привремени (`slike/favicon.svg`) у бојама сајта.
- (опционо) Галерија и даље користи Инстаграм уградњу; прелазак на сопствене фотографије остаје могућност за касније, брже се учитава и не зависи од туђе услуге.

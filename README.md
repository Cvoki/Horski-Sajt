# Хор „Свети Владика Николај Српски" - Нова Пазова

Сајт мешовитог хора при храму Свете Петке у Новој Пазови. Јekyll сајт на српској ћирилици, хостован на GitHub Pages, са уграђеним admin панелом (Decap CMS) за вести и календар наступа.

**Инстаграм:** [@hornovapazova](https://www.instagram.com/hornovapazova) · **Фејсбук:** [HorNovaPazova](https://www.facebook.com/HorNovaPazova) · **Јутјуб:** [канал хора](https://www.youtube.com/channel/UCHeA3i_Rdq_KfHwoMIjTJKg)

**Сајт уживо:** [cvoki.github.io/Horski-Sajt](https://cvoki.github.io/Horski-Sajt/)

## О пројекту

Хор је основан 2005. године, благословом Епископа сремског Господина Василија, и данас броји 24 члана. Сајт окупља на једном месту оно што је до тада било расуто по друштвеним мрежама: ко су, шта певају, где наступају и како им се јавити.

Сајт је **Jekyll** статички генератор (GitHub Pages га сам гради при сваком push-у, без потребе за посебним CI подешавањем), а вести и календар наступа уређују се кроз **admin панел** (`/admin/`) базиран на [Decap CMS](https://decapcms.org/) — измене се чувају директно у овом Git репозиторијуму, без базе података и без месечних трошкова хостинга.

Цео садржај је на **српској ћирилици**, што за овакав сајт није техничка ситница него део карактера.

## Странице

| Страница | Садржај |
|---|---|
| `/` (`index.html`) | Насловна — вест о наредном догађају, видео наступа |
| `/o_nama.html` | О хору: оснивање 2005, састав, репертоар |
| `/dogadjaji.html` | Догађаји — листа предстојећих наступа + месечни календар |
| `/vesti/` | Вести — свака вест на својој страници (уређује се кроз admin панел) |
| `/galerija.html` | Галерија фотографија (уређује се кроз admin панел) |
| `/crkva.html` | О храму Свете Петке: историјат Нове Пазове, градња храма, житије светитељке |
| `/kontakt.html` | Контакт форма и Гугл мапа са локацијом храма |
| `/admin/` | Admin панел за уређивање вести, догађаја, галерије и контакт података |

## Технологије

`Jekyll` · `HTML5` · `CSS3` · `Bootstrap 5.0` · `Decap CMS` · `formsubmit.co` · `GitHub Pages`

Jekyll и Bootstrap се сами граде/учитавају (Jekyll преко `github-pages` gem-а који GitHub Pages нативно подржава, Bootstrap са CDN-а). Контакт форма шаље поруке преко [formsubmit.co](https://formsubmit.co) — без сопственог налога, директно на имејл хора. Admin панел (Decap CMS) чува измене као фајлове у овом репозиторијуму, а за пријаву захтева GitHub налог — видети [Admin панел](#admin-панел) испод.

## Структура

```
.
├── _config.yml            # Jekyll подешавања (наслов, колекције, plugin-ови)
├── Gemfile                # Ruby зависности (github-pages gem)
├── _layouts/              # дељени шаблони страница (default, page, vest)
├── _includes/             # дељени делови (header/nav, footer, картице, календар)
├── _data/
│   ├── nav.yml            # ставке навигације
│   └── site_settings.yml  # контакт подаци и друштвене мреже (уређује се кроз admin панел)
├── _vesti/                # вести — један .md фајл по вести (колекција)
├── _dogadjaji/            # наступи/догађаји — један .md фајл по догађају (колекција)
├── _galerija/             # фотографије галерије (колекција)
├── admin/
│   ├── index.html         # Decap CMS admin панел
│   └── config.yml         # подешавање колекција и GitHub пријаве
├── assets/
│   ├── css/style.css      # сви стилови
│   ├── js/main.js         # календар навигација, потврда слања контакт форме
│   └── img/
│       ├── icons/         # favicon и иконице друштвених мрежа
│       └── uploads/       # слике додате кроз admin панел
├── index.html, o_nama.html, dogadjaji/, vesti/, galerija.html, crkva.html, kontakt.html, 404.html
├── robots.txt
└── sitemap.xml            # генерише га jekyll-sitemap plugin аутоматски (није ручно писан)
```

## Изглед

Боје су преузете из самог храма и црквене традиције, дефинисане као CSS променљиве у `assets/css/style.css`:

| Боја | Код | Где се користи |
|---|---|---|
| Тамноцрвена | `#af1d1c` | заглавље, подножје, hero, дугмад |
| Златна | `#c7a658` | линкови при прелазу мишем, поља форме, акценти |
| Крем позадина | `#f3f1ec` | позадина странице |

Типографија: **Cormorant Garamond** за наслове, **PT Sans** за текст (оба са пуном подршком за ћирилицу, учитавају се са Google Fonts).

Странице које немају праву фотографију (вести, догађаји, галерија) приказују дискретан gradient placeholder уместо покиданог `<img>` — чим се права слика дода кроз admin панел, аутоматски се приказује.

Навигација користи Bootstrap `navbar` који се на ужим екранима скупља у дугме, тако да сајт ради и на телефону.

## Покретање локално

Потребан је Ruby (препоручено: [RubyInstaller +DevKit](https://rubyinstaller.org/) на Windows-у) и Jekyll.

```bash
git clone https://github.com/Cvoki/Horski-Sajt.git
cd Horski-Sajt
gem install bundler jekyll
bundle install
bundle exec jekyll serve --livereload
```

Сајт је доступан на `http://localhost:4000/Horski-Sajt/` (напомена: путања укључује `/Horski-Sajt` пошто је то и путања на живом сајту).

### Локално тестирање admin панела

```bash
npx decap-server
```

па отвори `http://localhost:4000/Horski-Sajt/admin/` — локално ово ради без GitHub пријаве (директно чита/пише фајлове у радном директоријуму).

## Admin панел

На живом сајту, `/admin/` захтева пријаву GitHub налогом који има write приступ овом репозиторијуму. Пошто сајт остаје на GitHub Pages (не на Netlify), GitHub пријава ради преко посебног, малог OAuth "proxy" сервиса (нпр. бесплатан Cloudflare Worker) — то се подешава једном, ван овог репозиторијума:

1. Направити GitHub OAuth App (github.com → Settings → Developer settings → OAuth Apps).
2. Deploy-овати бесплатан OAuth proxy (нпр. [`sveltia-cms-auth`](https://github.com/sveltia/sveltia-cms-auth) на Cloudflare Workers).
3. Уписати добијени URL у `admin/config.yml` (`backend.base_url`).

Кроз admin панел се уређују: **Вести**, **Догађаји** (календар наступа), **Галерија** и **Општа подешавања** (телефон, е-пошта, адреса, друштвене мреже, ручна порука за "Наредни догађај" на насловној).

## Измене садржаја

- **Вести, догађаји, галерија, контакт подаци** — кроз admin панел (`/admin/`), без додиривања кода.
- **Нова статична страница** (ван admin панела) — копирати `crkva.html` или `o_nama.html` и заменити садржај; `layout: page` у заглављу фајла аутоматски додаје заглавље/подножје/путању.
- **Навигација** — једно место, `_data/nav.yml`.
- **Изглед** — све је у `assets/css/style.css`; Bootstrap класе носе мрежу и распоред.

## Шта остаје да се уради

- **Праве фотографије** хора, храма и наступа — тренутно их нема у репозиторијуму; додају се кроз admin панел (`assets/img/uploads/`).
- **Прави подаци о наступима** — унети кроз admin панел (колекција "Догађаји") када хор достави распоред.
- **Прве вести** — унети кроз admin панел када хор пожели да их објави.
- **Deploy OAuth proxy-ja** за GitHub пријаву на admin панелу (види [Admin панел](#admin-панел)) — једнократно подешавање ван репозиторијума.
- **Прави лого/фавикон** хора — тренутно стоји привремени (`assets/img/icons/favicon.svg`) у бојама сајта.
